API

TimeboardApp ships with a documented JSON API (OpenAPI). Use it for automation, integrations, and management workflows.

API documentation

On any running TimeboardApp instance, you can browse:

  • /docs — Swagger UI
  • /openapi.json — OpenAPI schema
Base URL
Examples below use http://localhost:8888. Replace with your deployment origin.

Authentication

The API uses a bearer token. First, exchange a username/password for an access token: 

curl -X POST "http://localhost:8888/api/auth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=YOUR_PASSWORD"

The response includes access_token. Use it as:

Authorization: Bearer <token>

Example:

TOKEN="$(curl -s -X POST "http://localhost:8888/api/auth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=YOUR_PASSWORD" | python -c "import sys, json; print(json.load(sys.stdin)['access_token'])")"

curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:8888/api/auth/me"

Key endpoints

AreaPrefixNotes
Auth /api/auth Token issuance and current user
Tasks /api/tasks Create tasks, complete tasks, schedule recurrence, list by status
Tags /api/tags Manage tags and task/tag mappings
Notifications /api/notifications Notification services and user settings
Metrics /api/metrics User, deployment, Prometheus, and InfluxDB metrics exports
Homepage /api/homepage Compact JSON payloads for GetHomepage.dev Custom API widgets
Admin /api/admin Admin-only endpoints for email, logging, WNS, and logs

For exact request/response schemas, use /docs on your running instance.

Tasks summary endpoint

GET /api/tasks/summary returns summary totals for the authenticated user inferred from the bearer token. The payload includes archived, past_due, all_upcoming_due, due_in_0_8h, due_in_8_24h, and due_in_over_24h.

Metrics endpoints

Use these endpoints to feed external metrics collectors such as InfluxDB/Grafana or Prometheus-compatible scrapers.

MethodPathScopeFormat
GET/api/metrics/catalogAuthenticated userJSON endpoint catalog
GET/api/metrics/meAuthenticated userJSON current-user metrics
GET/api/metrics/usersAdminJSON metrics for all users
GET/api/metrics/users/{user_id}Admin or same userJSON metrics for one user
GET/api/metrics/deploymentAdminJSON deployment metrics
GET/api/metrics/prometheusAdminPrometheus text exposition
GET/api/metrics/influxAdminInfluxDB line protocol

Metrics include task status counts, due buckets, recent activity, completion timing, overdue time, notification service counts, notification event counts, and deployment runtime.

Homepage Custom API endpoints

These endpoints return compact top-level JSON fields for GetHomepage.dev Custom API widgets.

MethodPathScopePurpose
GET/api/homepage/summaryAuthenticated userCurrent user's active, overdue, completion, and time metrics
GET/api/homepage/deploymentAdminDeployment totals, notification failures, and uptime
GET/api/homepage/usersAdminDynamic-list-friendly user summary rows
 
- TimeboardApp:
    widget:
      type: customapi
      url: https://timeboard.example.com/api/homepage/summary
      headers:
        Authorization: Bearer YOUR_TOKEN
      mappings:
        - field: active
          label: Active
          format: number
        - field: past_due
          label: Past due
          format: number
